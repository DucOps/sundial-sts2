# Defect

**Coverage status: draft — not yet played.** Descriptive only, from game text and community sources. Archetypes
are generated from game text and no cards are annotated; the run summary's roles come from card text.

## Kit and core resource

75 HP. Cracked Core: Channel 1 Lightning at the start of each combat. Starts with Strikes, Defends, Zap (Channel 1
Lightning) and Dualcast (Evoke your rightmost Orb twice).

Core resource: **Orbs** in orb slots. Each orb has a passive effect each turn and a stronger effect when Evoked.
**Focus** increases the effect of orbs. Orb types include Lightning (damage), Frost (block), Dark (stored damage)
and Plasma (energy).

## What counts as real scaling

Focus gained for the fight, extra orb slots, and powers that keep producing orbs. Focus "this turn" is not scaling.
